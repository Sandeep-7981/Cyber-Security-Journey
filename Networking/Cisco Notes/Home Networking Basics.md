# 🏠 Home Network

## Definition

A **Home Network** is a group of connected devices within a house that share Internet access, files, and other resources.

### Common Devices

* Laptop
* Desktop
* Smartphone
* Smart TV
* Printer
* Gaming Console
* Smart Speaker
* IoT Devices

```text
              Internet
                  │
               Modem
                  │
               Router
        ┌─────────┼─────────┐
        │         │         │
    Laptop     Mobile    Smart TV
```

---

# 📡 Components of a Home Network

## ISP (Internet Service Provider)

Provides Internet connectivity.

Examples

* Airtel
* Jio
* BSNL

---

## Modem

Converts ISP signals into digital signals that devices can understand.

Function

* Connects home to ISP
* Provides Internet access

---

## Router

Connects multiple devices and directs network traffic.

Functions

* Shares Internet connection
* Assigns IP addresses (DHCP)
* Creates Wi-Fi network
* Connects wired and wireless devices

---

## Switch

Used when additional Ethernet ports are required.

Mostly used in offices and advanced home setups.

---

## Access Point

Provides wireless connectivity to devices.

Many home routers already include an Access Point.

---

# 🖥️ Home Network Topology

Most home networks use **Star Topology**.

```text
               Router
          /      |      \
      Laptop   Mobile   Smart TV
                   |
               Smart Speaker
```

Every device communicates through the router.

---

# 🌍 Network Technologies in the Home

## Ethernet

Uses physical cables.

Advantages

* High speed
* Stable connection
* Low latency

Common Uses

* Gaming PCs
* Smart TVs
* Desktop Computers

---

## Wi-Fi

Uses radio waves.

Advantages

* Wireless
* Easy to connect
* Supports multiple devices

Common Uses

* Mobile Phones
* Laptops
* Tablets

---

## Bluetooth

Short-range wireless communication.

Examples

* Wireless Earbuds
* Smart Watch
* Keyboard
* Mouse

---

# 📶 Wireless Standards (IEEE 802.11)

| Standard           | Frequency   | Maximum Speed             |
| ------------------ | ----------- | ------------------------- |
| 802.11b            | 2.4 GHz     | 11 Mbps                   |
| 802.11g            | 2.4 GHz     | 54 Mbps                   |
| 802.11n (Wi-Fi 4)  | 2.4 / 5 GHz | 600 Mbps                  |
| 802.11ac (Wi-Fi 5) | 5 GHz       | Several Gbps              |
| 802.11ax (Wi-Fi 6) | 2.4 / 5 GHz | Higher speed & efficiency |

---

# 🔒 Wireless Security

## WPA2

* AES Encryption
* Most widely used
* Good security

---

## WPA3

* Latest Wi-Fi security standard
* Stronger encryption
* Better protection against password attacks

---

# ⚙️ Setting Up a Home Router

Typical Steps

1. Connect modem to router.
2. Power on the router.
3. Open router configuration page.
4. Change default username and password.
5. Configure Wi-Fi name (SSID).
6. Set a strong WPA2/WPA3 password.
7. Save settings and restart if required.

---

# 🔐 Best Security Practices

✔ Change default admin password

✔ Use WPA3 or WPA2

✔ Disable WPS if not required

✔ Update router firmware regularly

✔ Use a strong Wi-Fi password

✔ Enable firewall

✔ Change default SSID if desired

# 🎤 Interview Q&A

### What is a home network?

A home network is a collection of interconnected devices that share Internet access and resources within a home.

---

### What is the difference between a modem and a router?

| Modem              | Router                         |
| ------------------ | ------------------------------ |
| Connects to ISP    | Connects devices together      |
| Provides Internet  | Shares Internet                |
| One WAN connection | Multiple LAN/Wi-Fi connections |

---

### What is the most common topology used in home networks?

**Star Topology**, where all devices connect to a central router.

---

### Which wireless standard is used by modern routers?

IEEE 802.11ax (Wi-Fi 6), although many routers also support Wi-Fi 5 (802.11ac).

---

### Which security protocol is recommended for home Wi-Fi?

WPA3 is recommended because it provides stronger encryption and improved protection compared to WPA2.

---

### Why should default router passwords be changed?

Default credentials are publicly known and can allow unauthorized access to the network.
