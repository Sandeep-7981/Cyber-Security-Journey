# 📖 Network Media

## Definition

**Network Media** is the physical or wireless path through which data travels from one device to another.

**Simple:** It is the communication channel used to transfer data.

---

# 📂 Types of Network Media

Network media is mainly divided into two categories:

```text
Network Media
│
├── Guided (Wired)
│
└── Unguided (Wireless)
```

---

# 🔌 Guided Media (Wired)

Uses physical cables to transmit data.

### Advantages

* Stable connection
* High speed
* Better security
* Less interference

### Disadvantages

* Requires cables
* Less mobility
* Installation cost

---

# 1. Twisted Pair Cable (UTP/STP)

Most commonly used cable in LANs.

Consists of pairs of twisted copper wires.

### Types

### UTP (Unshielded Twisted Pair)

* Low cost
* Easy installation
* Most common Ethernet cable

Examples

* Cat5e
* Cat6
* Cat6a

---

### STP (Shielded Twisted Pair)

* Additional shielding
* Better protection from interference
* Used in industrial environments

---

### Uses

* Home Networks
* Office Networks
* School Labs

```text
Computer ───────── Switch
```

---

# 2. Coaxial Cable

Contains a central copper conductor surrounded by insulation and shielding.

### Uses

* Cable Television
* Broadband Internet
* CCTV Systems

### Advantages

* Better shielding than UTP
* Longer distance support

### Disadvantages

* Less flexible
* Being replaced by fiber in many networks

---

# 3. Fiber Optic Cable

Uses **light pulses** instead of electrical signals.

### Types

### Single Mode Fiber (SMF)

* Long distance communication
* Used by ISPs and telecom companies

---

### Multi Mode Fiber (MMF)

* Short distance communication
* Used inside buildings and campuses

---

### Advantages

✔ Very high speed

✔ Long distance

✔ Immune to electromagnetic interference

✔ High bandwidth

---

### Disadvantages

✘ Expensive

✘ Difficult installation

---

```text
Light Signal

========== Fiber Cable ==========>

Very High Speed Data Transfer
```

---

# 📡 Unguided Media (Wireless)

Uses radio or electromagnetic waves instead of cables.

---

# 1. Wi-Fi

Wireless technology based on IEEE 802.11 standards.

### Uses

* Home Networks
* Office Networks
* Public Hotspots

Advantages

* Mobility
* Easy installation
* Supports multiple devices

---

# 2. Bluetooth

Short-range wireless communication.

### Range

Approximately 10 meters.

### Uses

* Wireless Earbuds
* Keyboard
* Mouse
* Smart Watch

---

# 3. Infrared (IR)

Uses infrared light waves.

### Characteristics

* Requires line-of-sight
* Very short range

Example

TV Remote Control

---

# 4. Cellular Network

Uses mobile towers for communication.

Examples

* 4G LTE
* 5G

Used for

* Mobile Internet
* Voice Calls
* Video Streaming

---

# 🎤 Interview Q&A

### What is network media?

Network media is the communication channel through which data travels between devices.

---

### What are the two main types of network media?

* Guided (Wired)
* Unguided (Wireless)

---

### Difference between UTP and STP?

| UTP             | STP            |
| --------------- | -------------- |
| No Shielding    | Shielded       |
| Low Cost        | Higher Cost    |
| Home/Office Use | Industrial Use |

---

### Why is Fiber Optic faster than Copper Cable?

Fiber optic uses light signals instead of electrical signals, allowing higher speed, longer distance, and less interference.

---

### Difference between Single Mode and Multi Mode Fiber?

| Single Mode      | Multi Mode           |
| ---------------- | -------------------- |
| Long Distance    | Short Distance       |
| Telecom Networks | Buildings & Campuses |

---

### Which network media is commonly used in home Wi-Fi?

Wireless media using radio waves (IEEE 802.11).
