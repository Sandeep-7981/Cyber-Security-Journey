# 🌐 02. Network Types

## 📖 Definition

**Network Types** classify computer networks based on their geographical coverage, size, and purpose.

**Simple:** Different networks are designed for different distances and uses.

---

# 📌 1. PAN (Personal Area Network)

### Definition

A **PAN** is a small network that connects personal devices within a short distance (usually 1–10 meters).

### Examples

* Mobile ↔ Bluetooth Earbuds
* Laptop ↔ Wireless Mouse
* Smartwatch ↔ Phone

### Advantages

* Low cost
* Easy to set up
* Low power consumption

### Disadvantages

* Very short range
* Limited number of devices

```
 Phone
   │
Bluetooth
   │
Smart Watch
   │
Earbuds
```

---

# 📌 2. LAN (Local Area Network)

### Definition

A **LAN** connects devices within a small geographical area such as a home, school, office, or laboratory.

### Examples

* Home Wi-Fi
* College Computer Lab
* Office Network

### Advantages

* High speed
* Low cost
* Easy resource sharing

### Disadvantages

* Limited coverage
* Requires maintenance

```
          Switch
      ┌────┼────┐
      │    │    │
    PC1   PC2  PC3
```

---

# 📌 3. WLAN (Wireless Local Area Network)

### Definition

A WLAN is a LAN that uses wireless communication instead of cables.

### Examples

* Home Wi-Fi
* College Wi-Fi
* Coffee Shop Wi-Fi

### Advantages

* Mobility
* No cables required
* Easy installation

### Disadvantages

* Lower security compared to wired LAN
* Signal interference

```
        Wi-Fi Router
        /    |    \
    Laptop Phone Tablet
```

---

# 📌 4. CAN (Campus Area Network)

### Definition

A CAN connects multiple LANs within a campus or organization.

### Examples

* University Campus
* Corporate Campus
* Hospital Buildings

```
 Building A
      │
 Building B
      │
 Building C
```

---

# 📌 5. MAN (Metropolitan Area Network)

### Definition

A MAN connects multiple LANs across a city or metropolitan area.

### Examples

* City Government Network
* Cable TV Network
* Large ISP Network

### Advantages

* Covers larger area than LAN
* High-speed connectivity

### Disadvantages

* Higher setup cost
* Complex management

```
Office A ─── Office B ─── Office C
        (Same City)
```

---

# 📌 6. WAN (Wide Area Network)

### Definition

A WAN connects networks across countries or continents.

### Examples

* The Internet
* Bank Networks
* International Company Networks

### Advantages

* Global communication
* Resource sharing across locations

### Disadvantages

* Higher latency
* Expensive infrastructure
* More security challenges

```
India Office
      │
Internet
      │
USA Office
```

# 🎤 Interview Q&A

### Q1. What is a PAN?

**Answer:**

A Personal Area Network (PAN) connects personal devices within a very short range, usually using Bluetooth or USB.

---

### Q2. What is the difference between LAN and WAN?

| LAN         | WAN                  |
| ----------- | -------------------- |
| Small area  | Large area           |
| High speed  | Comparatively slower |
| Low cost    | Expensive            |
| Home/Office | Internet             |

---

### Q3. What is WLAN?

**Answer:**

A Wireless Local Area Network (WLAN) is a LAN that uses Wi-Fi instead of physical cables.

---

### Q4. Which is the largest network in the world?

**Answer:**

The Internet is the largest WAN (Wide Area Network).

---

### Q5. Which network is commonly used in colleges?

**Answer:**

A Campus Area Network (CAN), which connects multiple LANs across the campus.
