# Introduction to OSINT

## What is OSINT?

**OSINT (Open Source Intelligence)** is the process of collecting and analyzing information from publicly available sources.

Unlike hacking, OSINT only uses information that is legally accessible to everyone.

Examples include:

- Websites
- Search engines
- Social media
- Public records
- News articles
- GitHub repositories
- DNS records
- Search engine caches
- Images
- Metadata

---

## Why is OSINT Important?

OSINT is widely used in:

- Cyber Security
- Threat Intelligence
- Penetration Testing
- Incident Response
- Digital Forensics
- Law Enforcement
- Journalism

---

## Common OSINT Sources

| Source | Example |
|---------|----------|
| Search Engines | Google, Bing |
| Social Media | LinkedIn, X, Facebook |
| DNS Records | WHOIS, DNS Lookup |
| Public Databases | Shodan, Censys |
| Git Repositories | GitHub |
| File Metadata | PDFs, Images |
| Archived Websites | Wayback Machine |

---

## Types of Information Collected

- Email addresses
- Usernames
- Phone numbers
- IP addresses
- Domain information
- Company details
- Employee information
- Documents
- Technologies used by websites
- Public code repositories

---

## Ethical Considerations

OSINT should always be:

- Legal
- Ethical
- Passive whenever possible
- Respectful of privacy
- Used only for authorized purposes

Never attempt unauthorized access while performing OSINT.

---

## Key Takeaway

OSINT is the foundation of reconnaissance.

Good intelligence gathering often determines the success of later security assessments.
